# Md Mehedi Hassan — Premium Denim Researcher Website

This package is prepared for **GitHub Pages**.

## Files

- `index.html` — homepage
- `research.html` — dedicated research page
- `profile.jpg` — profile photo
- `Mehedi-Hassan-CV.pdf` — downloadable CV
- `Hassan-ITAA-2025-Paper.pdf` — full ITAA paper
- `.nojekyll` — tells GitHub Pages to serve the site as plain static files
- `404.html` — branded not-found page
- `favicon.svg` — site icon
- `robots.txt` — crawler instructions
- `sitemap.xml` — sitemap template; replace YOUR-USERNAME and YOUR-REPOSITORY after creating the repo

## Publish on GitHub Pages

1. Create a new GitHub repository.
2. Upload **all files in this folder** to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. GitHub Pages will publish `index.html` as the entry page.

GitHub Pages supports static files and looks for `index.html` at the top level of the publishing source.

## Optional custom domain

After the GitHub Pages site is working, go to:

**Repository → Settings → Pages → Custom domain**

Then enter your domain and follow GitHub's DNS instructions.

For a professional academic site, a `www` domain is recommended, e.g. `www.example.com`.

## Important

Replace the placeholder URLs in `sitemap.xml` after you know your final GitHub Pages URL or custom domain.

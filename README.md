# Md Mehedi Hassan — Personal Academic Website

GitHub Pages-ready static website for Md Mehedi Hassan.

## Pages
- `index.html` — main profile
- `experience.html` — professional journey, **From Intern to Manager**
- `research.html` — research presentation
- `cv.html` — CV preview and PDF download

## Files
- `Mehedi-Hassan-CV.pdf` — downloadable CV
- `Hassan-ITAA-2025-Paper.pdf` — full research paper
- `profile.jpg` — profile image
- `.nojekyll` — keeps GitHub Pages from applying Jekyll processing
- `404.html`, `favicon.svg`, `robots.txt`, `sitemap.xml`

## GitHub Pages
Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.

## Custom domain
When `mehedihassan.com.bd` is approved, add it under Settings → Pages → Custom domain and configure the DNS records shown by GitHub/your registrar.
